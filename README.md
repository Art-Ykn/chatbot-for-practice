# Чат-бот для компании «ПБУ Фактура»

Для отчёта о производственной практике.  
Чат-бот отвечает на типовые вопросы клиентов бухгалтерской компании: услуги, цены, консультации, документы, безопасность, налоги, кадры.

-- Что использовалось:
- Python 3
- Flask (веб-сервер)
- HTML, CSS, JavaScript (виджет на сайт)

-- Развёртывание:
1. Установите зависимости: `pip install flask`
2. Запустите сервер: `python app.py`
3. Откройте в браузере: `http://127.0.0.1:5000/`

-- Структура :
- `app.py` — серверная логика, поиск ответов
- `knowledge_base.py` — база знаний (ключевые слова и ответы)
- `templates/index.html` — интерфейс чата

-- Пример работы:
- Пользователь: «Привет»  
  Бот: «Здравствуйте! Я бот компании «ПБУ Фактура»...»
- Пользователь: «Сколько стоит?»  
  Бот: «Стоимость зависит от системы налогообложения...»

Правда он там сразу здоровается и ещё после приветствия пользователя.
